# Testzugang und Bestellung

## Testzugang, 7 Tage

Kostenlos, voller Funktionsumfang, ohne Verpflichtung.

Anfrage an **rm@kostenmanager.net** mit:

```
Firma / Behörde:
Ansprechpartner:
```

Sie erhalten den Testschlüssel per E-Mail, in der Regel am selben Werktag.

## Dauerlizenz

Unbefristet, 99 € einmalig je Arbeitsplatz, ausgestellt auf Ihre Organisation.
Einstellungen und Profile aus dem Test bleiben erhalten.

Bestellung an **rm@kostenmanager.net**:

```
Firma / Behörde:
Ansprechpartner:
Rechnungsanschrift:
USt-IdNr. (falls vorhanden):

Zahl der Arbeitsplätze:
```

Sie erhalten ein Angebot. Nach Zahlungseingang wird der Lizenzschlüssel per
E-Mail zugestellt.

## Schlüssel eintragen

In der Oberfläche (`http://localhost:9999`): Ohne gültigen Schlüssel
erscheint das Eingabefeld direkt. Einen bestehenden Schlüssel ersetzen Sie
über die Lizenzanzeige oben rechts.

Oder in der Datei `.env` im Installationsverzeichnis:

```
LICENSE_KEY=KIX1....
```

Danach neu starten:

```bash
docker compose up -d
```

Der Schlüssel wird lokal geprüft. Es findet keine Onlineaktivierung statt und
es werden keine Daten übertragen.
